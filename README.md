# M1 Risks - GIS Programming: working with AI

Homework for the M1 Risks GIS Programming course (Université Côte d'Azur).

**`HW_Working_With_AI.ipynb`** contains everything: an introduction (how to work with an AI, my doubts and convictions) and the exercises A to F, including a short Python script to read (exercise C).

## How to use
1. Copy the notebook into your own project repository (in PyCharm, or download it from GitHub). It also runs in Google Colab.
2. Do the exercises and write your answers directly in the notebook.
3. Commit and push.
