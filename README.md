# M1 Risks - GIS Programming: working with AI

Homework for the M1 Risks GIS Programming course (Université Côte d'Azur).

**`HW_Working_With_AI.ipynb`** contains everything: an introduction (how to work with an AI, my doubts and convictions) and the exercises A to F, including a short Python script to read (exercise C).

**[Open in Google Colab (no installation)](https://colab.research.google.com/github/pmannoni/MscRisks1_Homework1/blob/main/HW_Working_With_AI.ipynb)**

## How to use
This repository is **read-only for you**: do not push here.

1. Open the notebook in Colab with the link above, or download it (open the file on GitHub and use the download button).
2. Do the exercises and write your answers in the notebook. A Colab copy is not saved to GitHub: use *File > Download > .ipynb* when you finish.
3. Add the notebook to **your own project repository** (the one named like `m1risks-lastname-event`), next to your project notebook.
4. **Commit and push to your own repository.** That is the hand-in: I already have the link to your repository (if it is private, I must be a collaborator).
